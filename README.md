# python.01 Python Assignment 1 – Data Structures

Overview

This assignment covers basic Python data structures and string operations. It focuses on Strings and Tuples, including concatenation, slicing, indexing, string methods, tuple creation, and tuple access.

Topics Covered

1. String Concatenation

* Taking a name as input from the user
* Concatenating two strings
* Adding additional text to the existing string

2. String Slicing and Indexing

* Accessing the first character
* Accessing the last character
* Extracting the first 5 characters
* Extracting the last 11 characters
* Reversing a string
* Extracting the word “Python” using slicing

3. String Methods

* Converting a string to uppercase
* Converting a string to lowercase
* Using the capitalize() method
* Counting occurrences of a character
* Replacing a word using the replace() method

4. Tuples

* Creating tuples
* Concatenating two tuples
* Repeating tuple elements
* Accessing individual tuple elements
* Slicing the first and last elements

Technologies Used

* Python

Learning Outcome

This assignment helps to understand the basics of Python Strings, String Methods, String Slicing, Indexing, and Tuples.
